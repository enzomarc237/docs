The MCP API uses a set of shared object types that appear in responses across multiple endpoints. Understanding these types makes it easier to work with the structured data returned by `/mcp/list-screenshots`, `/mcp/get-screenshot-metadata`, and `/mcp/get-design-specifications`. Each type below is defined using a TypeScript interface that reflects the exact shape of the JSON objects in API responses.

## Layout structure

The `LayoutStructure` type describes the detected top-level arrangement of UI elements in a design. The `type` field uses a short identifier to name the detected pattern, and the open-ended `properties` object carries layout-specific measurements and configuration that vary depending on the type.

```typescript
{
  type: string;           // e.g., "grid", "flexbox", "horizontal", "vertical"
  description?: string;   // Human-readable description of the layout
  properties?: {          // Additional layout properties (columns, aspect_ratio, etc.)
    [key: string]: any;
  };
}
```

- `type` identifies the detected structural pattern (e.g., `"grid"` for column-based layouts, `"horizontal"` or `"vertical"` for flow-based layouts).
- `description` is a plain-English summary generated by the analysis engine.
- `properties` holds numeric and string values specific to the layout type — for a grid, you might find `columns`, `width`, `height`, and `aspect_ratio`.

## UI component

The `UIComponent` type represents a single interactive or visual element detected within a screenshot. Components are identified by their visual type, given a label when text is present, and located in the image using a `bounding_box` expressed in pixels from the top-left corner.

```typescript
{
  type: string;              // e.g., "button", "text_input", "image", "card"
  label?: string;            // Visible text label or placeholder text
  bounding_box?: {           // Pixel position within the image
    x: number;
    y: number;
    width: number;
    height: number;
  };
  properties?: {             // Component-specific visual properties
    [key: string]: any;
  };
}
```

- `type` names the kind of UI element, such as `"button"`, `"text_input"`, `"image"`, or `"card"`.
- `label` captures any visible text associated with the component (button labels, input placeholders, card headings).
- `bounding_box` gives the pixel coordinates and dimensions of the component's position within the screenshot image.
- `properties` is a flexible bag of component-specific attributes — common keys include `background_color`, `text_color`, `border_radius`, `placeholder`, and `input_type`.

## Color info

The `ColorInfo` type represents a single color entry in a screenshot's extracted palette. Each entry combines the raw hex value with semantic metadata that helps AI agents understand how the color is used in the design.

```typescript
{
  hex: string;               // e.g., "#FFFFFF"
  role?: string;             // e.g., "primary", "secondary", "background"
  usage_context?: string;    // e.g., "button_background", "text_color"
  proportion?: number;       // 0.0 to 1.0 — fraction of image covered
}
```

- `hex` is the standard six-digit hex color code.
- `role` assigns a semantic label to the color's function in the design system (e.g., `"primary"` for brand colors, `"background"` for surface colors).
- `usage_context` provides a more specific label for where the color appears (e.g., `"buttons_links"`, `"main_background"`, `"body_text"`).
- `proportion` is a floating-point value between `0.0` and `1.0` expressing roughly what fraction of the image is covered by this color.

## Typography style

The `TypographyStyle` type describes a single text style detected in the screenshot. It captures font identity, sizing, weight, and color alongside a sample of the actual text and a label for the text's semantic role in the design hierarchy.

```typescript
{
  font_family?: string;            // e.g., "Roboto", "San Francisco"
  font_size_px?: number;           // Font size in pixels
  font_weight?: string | number;   // e.g., "bold", 400, 700
  font_style?: string;             // e.g., "normal", "italic"
  line_height_ratio?: number;      // Ratio relative to font size (e.g., 1.5)
  color_hex?: string;              // e.g., "#000000"
  sample_text?: string;            // Short excerpt of text in this style
  context?: string;                // e.g., "heading_1", "body_text", "caption"
}
```

- `font_family` names the detected typeface.
- `font_size_px` gives the size in pixels as measured or inferred from the image.
- `font_weight` accepts either a numeric value (`400` for regular, `700` for bold) or a keyword string (`"bold"`).
- `line_height_ratio` is a multiplier relative to the font size — a value of `1.5` means the line height is 1.5 times the font size.
- `color_hex` is the text color as a hex code.
- `sample_text` is a short excerpt of text rendered in this style, taken directly from the screenshot when available.
- `context` is a semantic role label that places the style in the design hierarchy (e.g., `"heading_1"`, `"body_text"`, `"caption"`, `"label"`).
