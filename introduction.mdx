AI Design Inspiration Hub is a native macOS desktop application that serves as a centralized repository for UI screenshots and wireframes. It lets designers curate and organize design inspiration, then exposes that library to AI agents through a secure, locally hosted Model Context Protocol (MCP) server — so your AI tools can query, filter, and retrieve design specifications programmatically.

## What it does

You upload screenshots and wireframes, enrich them with titles, tags, and categories, and the app automatically analyzes each image to extract color palettes, layout information, and UI component details. Once your library is populated, you start the built-in MCP server and generate an API key. Any AI agent that can make HTTP requests can then list your screenshots, fetch metadata for a specific design, or pull structured design specifications — all from `http://localhost:8080`.

All data is stored locally on your machine using SQLite. There is no cloud sync, and the MCP server only accepts connections from localhost.

## Who it's for

AI Design Inspiration Hub is built for two audiences who often work together:

**Designers** who want a dedicated home for UI inspiration — somewhere to save, tag, and search screenshots without relying on general-purpose tools that weren't built for design assets.

**AI developers** who want to give their agents access to a curated, structured design library. Instead of embedding design context in prompts or managing files manually, you point your agent at the MCP server and let it query your library directly.
