A well-organized library makes the difference between quickly finding the right design reference and scrolling through hundreds of screenshots. AI Design Inspiration Hub gives you two complementary tools for organization: tags for flexible labeling and categories for hierarchical grouping.

## Tags

Tags are short, flexible labels you attach to screenshots. A single screenshot can have as many tags as you like. Tags are searchable and filterable, and they are the primary way AI agents discover relevant designs.

Good tags describe:

- **Design patterns** — `carousel`, `form`, `navigation`, `modal`
- **Platforms** — `mobile`, `web`, `desktop`
- **Visual styles** — `minimalist`, `modern`, `dark-mode`
- **Industries** — `ecommerce`, `healthcare`, `fintech`

<AccordionGroup>
  <Accordion title="Best practices for tags">
    - Use **lowercase** for consistency — `mobile` not `Mobile`
    - Keep tags **short and specific** — prefer `login-form` over `form-for-logging-in`
    - Build a **personal vocabulary** and stick to it across all uploads
    - Add **at least three tags** per screenshot — more tags means AI agents can find it in more contexts
    - Combine platform and pattern tags — `mobile` + `checkout` is more useful than either alone
  </Accordion>
  <Accordion title="Tag examples">
    | Tag | When to use |
    |-----|-------------|
    | `mobile` | Designs intended for small screens |
    | `dashboard` | Admin panels, analytics views, data overviews |
    | `form` | Input forms, surveys, registration flows |
    | `onboarding` | Welcome screens, setup wizards, tutorial flows |
    | `dark-mode` | Designs with a dark color scheme |
  </Accordion>
</AccordionGroup>

<Tip>
Adding 3 or more tags per screenshot significantly improves how well AI agents can find and recommend relevant designs from your library.
</Tip>

## Categories

Categories provide a higher-level structure for your library. Where tags are flat and flexible, categories are meant to group screenshots into broad, named buckets — think of them as folders.

Common categories include:

- **Authentication** — login screens, signup flows, password reset
- **E-commerce** — product pages, checkout flows, shopping carts
- **Dashboards** — analytics panels, admin views, reporting screens
- **Mobile Apps** — iOS, Android, and cross-platform designs

A screenshot can belong to more than one category, but keeping each screenshot in one to three categories makes browsing more predictable.

<AccordionGroup>
  <Accordion title="Best practices for categories">
    - Create **broad categories** for major design types (e.g., `Authentication`, `E-commerce`)
    - Use **sub-categories** for specific use cases within a broader area (e.g., `Mobile Apps > iOS`)
    - Assign **one to three categories** per screenshot to avoid diluting the grouping
    - Keep **naming conventions consistent** — choose between title case and lowercase and apply it everywhere
  </Accordion>
  <Accordion title="Category examples">
    | Category | What belongs here |
    |----------|-------------------|
    | `Authentication` | Login, signup, password reset, two-factor prompts |
    | `E-commerce` | Product listings, cart, checkout, order confirmation |
    | `Dashboards` | Admin panels, analytics views, report screens |
    | `Mobile Apps` | Native iOS or Android designs, responsive mobile views |
  </Accordion>
</AccordionGroup>

## Editing metadata

To update the tags or categories on an existing screenshot:

1. Click the screenshot in the grid to open the detail view.
2. Click the edit icon to open the metadata form.
3. Update any fields — title, description, tags, categories, or source URL.
4. Save your changes.
